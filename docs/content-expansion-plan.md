# English Quest Content Expansion Plan

## 目的

English Quest の問題・ショップ・解放要素を、特定言語や特定モードへ偏らせず、継続的に拡充するための計画書です。

今後のコンテンツ追加・ゲームバランス調整・Neon Database 反映・デプロイ作業は、この計画に従って実施します。

## 基本方針

| 項目 | 方針 |
| --- | --- |
| 対象 | 単語、文法、会話、文化、リスニング、スピーキング、タイピング |
| 言語 | 既存対応言語を優先し、100言語単位など区切りのよい単位で拡張 |
| レベル | Lv.1 から Lv.10 まで偏りなく配置 |
| DB | Neon Database を正とし、ローカル共有データは fallback として同期 |
| 品質 | 重複、正解不一致、選択肢不足、音声未対応、表記ゆれを検査 |
| 権利 | アイテム名、敵キャラ名、世界観はオリジナル名称を使用 |

## 問題拡充の目標

### 最低基準

| カテゴリ | 言語ごとの最低目標 | レベル配分 |
| --- | ---: | --- |
| 単語 | 200問 | Lv.1-10 に各20問 |
| 文法 | 100問 | Lv.1-10 に各10問 |
| 会話 | 50問 | Lv.1-10 に各5問 |
| 文化 | 30問 | 地域・国別に分散 |
| リスニング | 単語・会話問題から生成 | 音声対応状況を確認 |
| スピーキング | 単語・会話問題から生成 | 発音練習に適した短文中心 |
| タイピング | 各言語の文字体系に対応 | PC配列・スマホ入力の両方を考慮 |

### 拡充優先順位

1. 文法問題を全対応言語で均等化する
2. 単語問題を Lv.1-10 へ均等に追加する
3. 会話・フレーズ問題を地域別に追加する
4. 文化問題を国・地域ごとに追加する
5. 音声が出ない言語の代替・案内・TTS対応を改善する
6. 忘却曲線・スマート学習向けのメタデータを強化する

## 追加単位

| 単位 | 内容 |
| --- | --- |
| 小単位 | 1言語または1地域の不足分を補完 |
| 標準単位 | 100問単位で追加、seed、build、commit、push、deploy |
| 大単位 | 100言語単位で集計、追加、Neon反映、検証 |

作業は「切りのよい単位」で区切り、各区切りごとに以下を実施します。

1. 不足数の集計
2. 問題データ追加
3. 重複・整合性チェック
4. Neon Database への seed
5. build
6. セキュリティ確認
7. commit
8. push
9. deploy

## Neon Database 連携ルール

Neon Database を使う前提で、問題データ追加時は以下を守ります。

| 項目 | ルール |
| --- | --- |
| 接続 | `.env` の `DATABASE_URL` / `DIRECT_URL` を使用 |
| 反映 | `server/prisma/seed.js` で upsert |
| 削除 | 原則として既存問題は削除しない |
| 変更 | ID、正解、選択肢、レベル変更は影響範囲を確認 |
| 検証 | DB件数、カテゴリ別件数、言語別件数を確認 |
| fallback | `shared/questionData.js` も同期し、API障害時に動作させる |

## Shop 解放設計

Shop は単なる回復アイテム販売ではなく、学習範囲・探索範囲・便利機能を段階的に解放する場所とします。

### 商品カテゴリ

| カテゴリ | 例 | 用途 |
| --- | --- | --- |
| 回復 | いやしのしずく、集中の香 | HP・MP回復 |
| 学習補助 | ヒントの羽ペン、選択肢けしの札 | ヒント、選択肢削減 |
| 問題解放 | 初級文法ノート、中級単語帳、上級会話巻物 | 問題カテゴリ・レベル解放 |
| 地域解放 | 旅人の通行証、大陸航路券 | 国・地域への入場条件 |
| マスター挑戦 | マスター試験券 | エンディング到達条件 |
| 忘却対策 | 復習の砂時計、記憶のしおり | 忘却曲線による低下を緩和 |

### レベル別価格帯

| レベル帯 | 解放内容 | 価格帯 |
| --- | --- | ---: |
| Lv.1-2 | 初級単語、初級文法、基本回復 | 50-150G |
| Lv.3-4 | 会話練習、ヒント系、地域入口 | 200-500G |
| Lv.5-6 | 中級文法、中級単語、探索許可 | 800-1,500G |
| Lv.7-8 | 上級問題、MP回復、高難度地域 | 2,000-4,000G |
| Lv.9-10 | マスター試験、忘却対策、終盤地域 | 5,000-10,000G |

### 解放条件

| 解放対象 | 条件 |
| --- | --- |
| 新しい言語 | Goldで言語パスを購入 |
| 新しい国・地域 | 必要アイテム、言語レベル、Gold条件を満たす |
| 高レベル問題 | 有効レベル到達 + 対応する教材アイテム購入 |
| スマート学習 | 基本機能は無料、詳細分析・復習補助はGoldで解放 |
| マスター試験 | Lv.10到達 + マスター試験券購入 |
| エンディング | 該当言語でマスターレベルを維持し、対象国で閲覧 |

## ゲームバランス方針

| 項目 | 方針 |
| --- | --- |
| Gold獲得 | 単語、文法、タイピングなど無料学習で獲得 |
| Gold消費 | Shop、地域解放、マスター試験、便利アイテムで消費 |
| 宿屋 | 宿泊には10G以上必要 |
| HP0 | Gold半減、宿屋から再開 |
| MP | ヒント、選択肢削減、回復魔法などに使用 |
| 難易度 | 問題レベル、地域、敵の強さ、報酬を連動 |
| 継続学習 | 忘却曲線でレベル低下し、復習で維持・回復 |

## コンテンツ品質基準

問題追加時は以下を満たします。

| 項目 | 基準 |
| --- | --- |
| 正解 | `answer` が `choices` に含まれている |
| 選択肢 | 原則4択、重複なし |
| ID | 言語・カテゴリ・連番で一意 |
| レベル | Lv.1-10 の範囲 |
| 日本語訳 | 自然で短く、学習者が理解しやすい |
| 文法解説 | 正解理由が分かる短い補足を付ける |
| 音声 | Web Speech API 非対応言語は案内または代替練習を用意 |
| 権利 | 実在作品・商標に依存した名称や設定を使わない |

## 実装ロードマップ

### Phase 1: 可視化

- 言語別、カテゴリ別、レベル別の問題数を集計する
- 不足している言語・カテゴリ・レベルを一覧化する
- Neon Database と fallback データの件数差分を確認する

### Phase 2: 問題拡充

- 文法問題を優先して均等追加する
- 単語問題を Lv.1-10 へ均等に追加する
- 会話・文化問題を地域ごとに追加する
- 100問ごと、または100言語ごとに seed、検証、commit、push、deploy する

### Phase 3: Shop 解放

- Shop商品マスタを定義する
- 商品に `requiredLevel`、`price`、`unlockType`、`target` を持たせる
- 学習カテゴリ、問題レベル、国・地域、便利機能を購入で解放する
- レベル帯に応じて価格を上げる

### Phase 4: 学習継続設計

- 忘却曲線に基づくレベル低下を実装・調整する
- 復習アイテムやスマート学習で維持しやすくする
- マスター試験、エンディング、再学習導線を整える

### Phase 5: 検証と運用

- `npm audit --audit-level=moderate`
- `npm run build`
- Neon seed 結果確認
- 主要画面の手動確認
- commit、push、deploy

# Content Guidelines

## 目的

問題データを安全かつ均等に追加するための基準です。

## 共通ルール

| 項目 | ルール |
| --- | --- |
| ID | 言語コード、カテゴリ、連番で一意にする |
| レベル | Lv.1-Lv.10 の範囲に収める |
| 検定タグ | `lv` から英語はTOEIC、主要言語は日本で参照されやすい検定またはCEFR相当へ分類できるようにする |
| 選択肢 | 原則4択、重複なし |
| 正解 | `answer` は必ず `choices` に含める |
| 解説 | 文法問題は短い解説を付ける |
| 表記 | 日本語訳は自然で短くする |
| 権利 | 既存作品・ブランド・キャラクター名を使わない |

## 文法問題

文法問題は、言語ごとに Lv.1-Lv.10 へ均等に追加します。

| レベル | 内容例 |
| --- | --- |
| Lv.1 | あいさつ、be動詞相当、基本語順 |
| Lv.2 | 否定、疑問、冠詞、基本時制 |
| Lv.3 | 形容詞、副詞、前置詞、助詞 |
| Lv.4 | 過去、未来、比較 |
| Lv.5 | 接続、関係表現、複文 |
| Lv.6 | 仮定、条件、助動詞 |
| Lv.7 | 敬語、文体差、自然な語順 |
| Lv.8 | ニュアンス、談話表現 |
| Lv.9 | 上級構文、抽象表現 |
| Lv.10 | マスター試験向け総合問題 |

## 単語問題

単語は頻度、実用性、地域性を考慮します。

| レベル | 内容例 |
| --- | --- |
| Lv.1-2 | 基本名詞、動詞、形容詞 |
| Lv.3-4 | 旅行、買い物、食事、道案内 |
| Lv.5-6 | 学校、仕事、ニュース |
| Lv.7-8 | 議論、説明、抽象語 |
| Lv.9-10 | 専門的・高度な語彙 |

## 検定レベル対応

各言語の問題は、ゲーム内Lv.1-Lv.10を維持しつつ、外部検定の目標に読み替えられるようにします。

| 言語 | 基準タグ | 方針 |
| --- | --- | --- |
| 英語 | TOEIC L&R | Lv.1=TOEIC300からLv.10=TOEIC990までの復習帯として扱う |
| 日本語 | JLPT | N5からN1まで段階的に語彙・文法・読解フレーズを増やす |
| 中国語 | HSK | HSK1からHSK6+まで語彙・語順・補語を段階配置する |
| 韓国語 | TOPIK | TOPIK IからTOPIK II上級まで語彙・文法・敬語を配置する |
| フランス語・スペイン語・ドイツ語・イタリア語等 | CEFR系検定 | A1からC2相当の到達目標で配置する |
| その他の言語 | CEFR相当 | 日本で一般的な検定が限定的な場合はCEFR相当タグを使い、検定情報は要確認として追記する |

## キーボード道場

選択言語のアルファベット、文字体系、一般的な入力方法に合わせます。

| 環境 | 方針 |
| --- | --- |
| PC | 対象言語の標準的な配列や入力設定を案内する |
| スマホ | 世界的に一般的な仮想キーボード入力を想定する |
| 未設定時 | 入力設定済みとみなせる簡易練習モードを用意する |

## 音声

Web Speech API で音声が出ない言語は、以下のいずれかで対応します。

- 対応voiceがない旨をUIで案内する
- 近い言語・地域のvoiceを代替候補として使う
- 音声なしでも成立するリスニング以外の練習へ誘導する

## レビュー観点

- 特定の言語だけ極端に問題が多くなっていないか
- Lv.1-Lv.10 の配分が崩れていないか
- 文化問題がステレオタイプや不正確な説明になっていないか
- 学習者にとって自然な表現か
- Neon seed と fallback の両方に反映されているか

# Security and Disclaimer

## セキュリティ方針

English Quest はOSSとして公開しますが、著作権は放棄しません。

公開環境で運用する場合は、利用者自身の責任で依存関係、環境変数、データベース、ログ、個人情報の取り扱いを確認します。

## 秘密情報

コミットしてはいけない情報:

- `.env`
- Neon Database の接続URL
- JWT秘密鍵
- APIキー
- 個人情報
- 未公開の財務・契約・業務情報

## 定期確認

```bash
npm audit --audit-level=moderate
```

必要に応じて、依存関係更新後に `npm run build` と主要画面の手動確認を行います。

# Game Design

## 基本ループ

1. フィールドで学習モードを選ぶ
2. 問題に回答してEXPとGoldを得る
3. GoldでShopアイテムや問題解放を購入する
4. 新しい国・地域・高レベル問題に挑戦する
5. 言語をマスターし、該当国でエンディングを見る
6. 忘却曲線により熟達度が下がるため、復習を続ける

## 学習モード

| モード | 目的 | Gold |
| --- | --- | --- |
| 単語学習 | 語彙の意味を覚える | 獲得可 |
| 文法学習 | 文法知識を定着させる | 獲得可 |
| キーボード道場 | 文字体系・入力方法を練習する | 獲得可 |
| 会話 | 実用フレーズを覚える | 獲得可 |
| 文化 | 国・地域理解を深める | 獲得可 |
| スマート学習 | 苦手・忘却曲線に基づいて復習する | 一部解放制 |

## Gold設計

Goldは学習によって獲得し、Shopで消費します。

| 使い道 | 例 |
| --- | --- |
| 回復 | HP回復、MP回復 |
| 補助 | ヒント、選択肢削減 |
| 解放 | 新言語、問題レベル、国・地域 |
| 挑戦 | マスター試験 |
| 継続 | 忘却対策アイテム |

## Shop価格設計

| レベル帯 | 価格帯 | 方針 |
| --- | ---: | --- |
| Lv.1-2 | 50-150G | 初心者がすぐ買える |
| Lv.3-4 | 200-500G | 会話・地域入口を解放 |
| Lv.5-6 | 800-1,500G | 中級教材・探索許可 |
| Lv.7-8 | 2,000-4,000G | 上級教材・強力アイテム |
| Lv.9-10 | 5,000-10,000G | マスター試験・忘却対策 |

## アイテム方針

アイテム、敵キャラ、地域演出はオリジナル名称を使い、既存ゲーム、漫画、映画、ブランド等の著作権・商標権を侵害しないようにします。

| 種類 | 例 |
| --- | --- |
| HP回復 | いやしのしずく |
| MP回復 | 集中の香 |
| ヒント | ヒントの羽ペン |
| 選択肢削減 | 選択肢けしの札 |
| 地域解放 | 旅人の通行証 |
| 忘却対策 | 復習の砂時計 |

## マスターと忘却曲線

言語のクリアポイントは「その言語をマスターしたこと」です。

マスター後も学習を続けない場合、忘却曲線に従って熟達度が下がります。新しい問題も追加されるため、一度マスターしても復習と追加学習が必要です。

## マップ設計

全体世界地図では、大陸アイコンのみを表示し、国旗アイコンは表示しません。

大陸に入った後は、その大陸・地域だけにフォーカスした地図に切り替え、主要言語アイコンを表示します。ユーラシアは広いため、ヨーロッパ、中東、東アジアなどに分割します。

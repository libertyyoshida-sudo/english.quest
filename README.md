# english.quest

英語を含む多言語学習を、RPG風のクイズ・タイピング・復習システムで進める学習ゲームです。

## 概要

- 単語、文法、フレーズ、文化・地理クイズ
- 忘却曲線を使った復習・定着度管理
- 言語ごとのマスター判定とエンディング
- キーボード道場による各言語の文字・配列練習
- Gold、Shop、アイテム、宿屋、世界マップなどのゲーム要素

## 開発環境

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

デプロイ:

```bash
npm run deploy
```
